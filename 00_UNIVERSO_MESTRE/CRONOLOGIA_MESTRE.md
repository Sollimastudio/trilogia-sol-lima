# CRONOLOGIA MESTRE — TRILOGIA SOL LIMA

## Função
Controlar a ordem real dos acontecimentos independentemente da ordem narrativa escolhida em cada livro.

A cronologia factual e a cronologia literária NÃO são a mesma coisa. Este arquivo registra a primeira. Os mapas de cada livro decidem a segunda.

## Marcadores
- [C] confirmado
- [M] memória
- [D] documentado
- [T] testemunho
- [R] revisar

## Regras de uso
1. Nunca alterar uma data para melhorar a literatura.
2. Quando houver dúvida, manter `[R]` até confirmação.
3. Uma memória pode ser verdadeira como experiência subjetiva mesmo quando a data exata não estiver disponível; nesse caso, narrar de forma compatível com o grau de certeza.
4. Se documentos e memória divergirem, registrar a divergência em vez de apagá-la.
5. Só depois de consolidada aqui uma sequência factual deve ser considerada segura para a revisão final de continuidade.
