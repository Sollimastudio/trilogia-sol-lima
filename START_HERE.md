## Regra de ouro
Cada livro cumpre sua própria promessa e planta apenas a pergunta necessária para o seguinte.

**Nenhum livro rouba a resposta do próximo.**

## Para um chat trabalhando em paralelo
Trabalhe apenas na pasta do livro designado. Não altere os arquivos de `00_UNIVERSO_MESTRE/` durante trabalho simultâneo, salvo ordem explícita da usuária para assumir coordenação do universo.

Antes de editar qualquer arquivo existente, releia a versão atual no GitHub.

## Versionamento obrigatório
- O arquivo vivo mostra o estado atual.
- `HISTORICO_ETAPAS.md` mostra a evolução de forma legível.
- `ETAPAS/` guarda snapshots dos marcos concluídos e não deve ter snapshots antigos sobrescritos.
- O histórico de commits do Git preserva tecnicamente cada mudança.

Antes de iniciar uma nova etapa, confirme que a anterior foi registrada no histórico e, quando for um marco estrutural, congelada em snapshot.
