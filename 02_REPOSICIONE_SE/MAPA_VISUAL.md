## 2. A Árvore do Discernimento — método central

### Ordem simbólica do cultivo

```mermaid
flowchart LR
    S[SEMENTE\natitude / decisão / prática] --> SO[SOLO\ncondições / ambiente]
    SO --> R[RAÍZES\nmodus operandi / mindset]
    R --> T[TRONCO\nvalores / limites / sustentação]
    T --> G[GALHOS\náreas da vida]
    G --> F[FRUTOS\nresultados observáveis]
```

> A ordem organiza a leitura; não afirma causa única ou linearidade psicológica rígida.

### Ordem da investigação

```mermaid
flowchart LR

    SS --> PR[PRAGAS]
    PR --> M[MIRANTE]

    FI --> C[CUSTOS / RECURSOS / RISCO]
    C --> PO[PODA]
    PO --> NS[NOVA SEMENTE]
    NS --> A[AÇÃO]
    A --> RF[REVISÃO PELOS FRUTOS]
```

## 3. A Casa que virou Jaula — ambiente narrativo

```mermaid
flowchart LR
    J[JAULA / CASA] --> S[SOFÁ QUENTE DA MENTIRA]
    S --> N[SONO DA NEGLIGÊNCIA]
    N --> P[PRAGAS]
    P --> B[PERTENCIMENTO / MERECIMENTO]
    B --> I[INFLUÊNCIAS]
    I --> D[PORTA POSSÍVEL]
    D --> SO[SOLEIRA]
    SO --> T[TRAVESSIA]
    T --> ST[SUSTENTAÇÃO]
```

### Comando transversal

```mermaid
flowchart TD
    E[EVIDÊNCIA SUFICIENTE] --> C[A JAULA ESTÁ ABERTA]
    C --> Q{Há segurança / recurso / margem?}
    Q -->|sim| M[MOVIMENTO POSSÍVEL]
    Q -->|não / ainda não| A[PLANEJAR / BUSCAR APOIO / DEIXAR NA ÁRVORE]
```

**A JAULA ESTÁ ABERTA não significa `saia agora`.** Significa: pare de fingir que não viu e investigue a margem real de movimento.

## 7. Fronteiras

- episódios de `Morte em Vida` entram apenas como exemplos breves;
- método completo fica no Livro 2;
- Fuga Identitária entra como pergunta/semente, não anatomia completa;
- Sepultamento Simbólico não vira ferramenta genérica do Livro 2;
- política é Galho de aplicação do discernimento, não palanque;
- o Livro 3 recebe a pergunta `quem é o Eu que está escolhendo?`.
