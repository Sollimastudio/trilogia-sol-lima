# CAPÍTULOS — MORTE EM VIDA

Esta pasta receberá o texto literário capítulo a capítulo.

## Padrão de arquivo
- `MV-00_NOTA_FORENSE_ABERTURA.md`
- `MV-01_OITO_DIAS_ANTES.md`
- `MV-02_DEZOITO_DE_JULHO.md`
- ...
- `MV-46_NOTA_FORENSE_FINAL.md`

## Cabeçalho obrigatório de cada capítulo
Cada arquivo deve começar com controle editorial:

- Código
- Título provisório
- Parte
- Lote
- Status
- Versão
- Função dramática
- Emoção de entrada
- Emoção de saída
- Sementes plantadas
- Ecos pagos
- Dependências/lacunas

Depois do cabeçalho começa o texto literário.

## Regra
A primeira versão pode ser escrita em massa por lote, mas cada capítulo permanece isolado para revisão, movimentação, fusão ou divisão sem corromper o restante do manuscrito.

Consultar antes de escrever:
1. `../MAPA_MAE.md`
2. `../MAPA_CAPITULOS.md`
3. `../PLANO_PRODUCAO_EM_MASSA.md`
4. `../INVENTARIO_DE_CENAS.md`
5. `../STATUS.md`

## Fluxo
estrutura → cenas → primeira escrita → continuidade do lote → revisão → fechamento.
